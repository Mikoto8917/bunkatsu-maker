# 分割メーカー

質問に答えると筋トレの分割法と週ごとのメニューを提案し、記録までできるWebアプリです。
自分で考えたオリジナルプランも作れます。

- 公開ページ: https://mikoto8917.github.io/bunkatsu-maker/
- 記録はその端末のブラウザの中（localStorage）にだけ保存されます。サーバーには送りません。

## 携帯のホーム画面に追加する

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: メニュー →「ホーム画面に追加」（または「アプリをインストール」）

一度開けば、電波がなくても使えます。
